# 传送锚点模型优化（防穿模 / 纯色水晶）设计文档

**日期：** 2026-08-15
**状态：** 已确认（Approved）
**方案：** A —— 生成脚本统一处理（几何上移 + 浮动减半 + 纯色贴图）

---

## 1. 问题陈述（Problem Statement）

三项模型优化：
1. **四角水晶穿模**：2×2×2 悬浮立方体（y11-13）浮动 ±0.25 格后最低 y10.75，距柱顶仅 0.75 格，玩家视角下视觉穿模。
2. **白色光球穿模**：核心光球（y13.25-14.75）浮动后最低 y13.125，与下方晶核顶（y13）仅差 0.125 格，脉冲放大时几乎贴死。
3. **四角水晶渐变贴图**：改为纯色（无渐变）。

## 2. 设计（Design）

### 2.1 架构（Architecture）

```
需求 1（四角水晶）：
  模型：caps ×8（青/红）y 11-13 → 12-14（上移 1 格）
  动画：CAP_AMPLITUDE 0.25 → 0.125（浮动减半）
  校验：最低 y11.875，柱顶 y10，间距 1.875 格 ✓

需求 2（白色光球）：
  模型：waypoint_orb.json + waypoint_orb_red.json  y 13.25-14.75 → 14.25-15.75（上移 1 格）
  动画：浮动 ±0.125 不变，脉冲缩放不变
  校验：最低 y14.125，晶核顶 y13，间距 1.125 格 ✓；最高 15.875 < 16 ✓

需求 3（纯色贴图）：
  新增 waypoint_caps.png（#6fe4f7）/ waypoint_caps_red.png（#fa6e5a）
  caps ×8 模型纹理引用从 waypoint_crystal(_red) 改为 waypoint_caps(_red)
```

### 2.2 组件（Components）

| 组件 | 文件 | 改动 |
|---|---|---|
| 生成脚本 | `blockbench/tools/generate_float_caps.mjs` | caps y12-14；纯色贴图生成 + caps 引用切换；orb 上移重写；自检含不穿模断言 |
| 纯色贴图 ×2 | `textures/block/waypoint_caps.png`、`waypoint_caps_red.png` | 新增 |
| 渲染器 | `WaypointBlockEntityRenderer.java` | `CAP_AMPLITUDE` 0.25 → 0.125 |

### 2.3 数据流（Data Flow）

无新数据流——纯几何/贴图/动画参数调整，客户端渲染与静态资源层生效。

### 2.4 错误处理（Error Handling）

| 场景 | 处理 |
|---|---|
| 纯色贴图缺失 | missing model 兜底（脚本自检） |
| orb 青/红上移遗漏 | 脚本同时重写 + 自检断言 |
| caps 顶 y14 + 浮动 0.125 | 不与能量环（y8.5-9.5）干涉 ✓ |

### 2.5 测试策略（Testing Strategy）

1. 四角水晶任意相位与柱子间距 ≥1.75 格；纯色无渐变。
2. 光球任意时刻与晶核间距 ≥1 格；不越出方块。
3. 红/青两组一致；动画正常；构建通过。

### 2.6 性能（Performance）

无新增渲染开销；纯色贴图文件更小。

## 3. 决策记录（Decisions Made）

- caps 上移 1 格 + 浮动减半（用户选择）。
- 纯色取更亮发光色：青 #6fe4f7 / 红 #fa6e5a（用户选择）。
- 光球上移 1 格（y14.25-15.75），浮动范围不变（用户要求）。

## 4. 非目标（Non-Goals）

- 中央晶核/能量环/光球的贴图渐变保留（仅四角水晶纯色）。
- 动画速率调整（仅幅度）。

## 5. 后续步骤（Next Steps）

1. 扩展 generate_float_caps.mjs（几何 + 纯色 + orb 上移 + 自检）。
2. 渲染器 CAP_AMPLITUDE。
3. 构建验证 + 游戏实测。
