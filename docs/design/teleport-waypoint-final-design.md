# Teleport Waypoint 最终设计文档

**版本:** 0.2.0  
**日期:** 2026-08-20  
**状态:** 最终设计  
**Mod ID:** `teleportwaypoint`  
**Minecraft / NeoForge:** 1.21.1 / 21.1.236+

---

## 1. 概述

Teleport Waypoint（传送锚点）是一个 Minecraft NeoForge 模组。玩家可以在世界中放置锚点，右键激活后即可在任意已激活锚点之间传送，支持跨维度。

模组提供两种锚点：

- **传送锚点（Waypoint）**：偏“公共/结构”用途，通常由自然结构生成或创造模式放置。
- **口袋锚点（Pocket Waypoint）**：偏“个人”用途，可合成，绑定放置者，可自由命名。

---

## 2. 设计目标与非目标

### 目标

- 提供简单、直观的跨维度传送体验。
- 服务端权威，防止客户端伪造传送/改名请求。
- 保护口袋锚点隐私：未激活口袋锚点不发送给客户端。
- 与 Xaero 小地图/世界地图深度联动，并严格按维度隔离。
- 结构生成与数据包可配置、可选。

### 非目标

- 不做客户端持久化锚点缓存。
- 不做未激活普通锚点的“区块范围流式同步”。
- 不改变原版传送/战斗机制。
- 不提供跨模组通用传送 API（当前仅内部使用）。

---

## 3. 核心概念

### 3.1 传送锚点（Waypoint）

- 方块 ID：`teleportwaypoint:waypoint`
- 黑曜石级硬度/抗爆：`50` / `1200`
- 需要钻石镐才能破坏，无掉落物。
- 命名方式：ID + 翻译键，例如 `village` → `teleportwaypoint.waypoint.village`。
- 所有者：无。
- 改名权限：仅创造模式玩家。

### 3.2 口袋锚点（Pocket Waypoint）

- 方块 ID：`teleportwaypoint:pocket_waypoint`
- 石头硬度/黑曜石抗爆：`1.5` / `1200`
- 需要镐破坏，掉落自身。
- 命名方式：自由文本，最长 64 字符，空名称回退为 `Pocket Waypoint`。
- 所有者：放置者 UUID。
- 改名权限：所有者；创造模式玩家可改任意口袋锚点。

### 3.3 激活状态

- 激活状态按“玩家 UUID → 锚点 UID 集合”保存。
- 每名玩家独立。
- 普通锚点与口袋锚点都可以被任意玩家激活。
- 激活状态持久化到世界存档。

### 3.4 UID

- 每个锚点方块实体有一个全局唯一 `UUID`。
- 复制/粘贴导致 UID 冲突时，服务端自动重新生成 UID。
- UID 是传送请求、激活记录、网络同步的核心标识。

## 4. 方块与物品

### 4.1 方块

| 方块 | 硬度 | 抗爆 | 可破坏 | 掉落 | 含水 |
|---|---|---|---|---|---|
| 传送锚点 | 50 | 1200 | 是（钻石镐） | 无 | 是 |
| 口袋锚点 | 1.5 | 1200 | 是（镐） | 掉落自身 | 是 |

### 4.2 物品

- 两个方块都有对应 `BlockItem`。
- 创造模式标签页 `itemGroup.teleportwaypoint` 包含全部锚点物品。
- 口袋锚点有合成配方：回响碎片 + 末影珍珠 + 末地水晶。

### 4.3 方块实体

- 两种方块共用 `WaypointBlockEntity`。
- NBT 按类型保存：
  - 普通锚点：`uid` + `waypoint_id`；
  - 口袋锚点：`uid` + `name` + `owner`。
- 服务端加载时自动注册到全局索引。

## 5. 交互流程

### 5.1 放置

- 放下锚点后自动激活，并打开命名界面。
- 普通锚点：输入 `[a-z0-9_]*`，空值回退为 `empty`。
- 口袋锚点：输入任意名称，空值回退为 `Pocket Waypoint`。

### 5.2 右键

- 未激活锚点：仅激活，播放经验球音效并提示，不打开 GUI。
- 已激活锚点：打开传送列表 GUI。
- 潜行 + 右键：打开改名界面（需有权限）。

### 5.3 激活

- 任意玩家可激活任意锚点。
- 激活后写入玩家数据，并同步客户端。

### 5.4 取消激活 / 删除激活

- 传送列表中的 ✕ 按钮只取消激活，不破坏方块。
- 删除前有确认弹窗。
- 如果删除的是当前正在使用的锚点，GUI 自动关闭。

## 6. 传送系统

### 6.1 传送规则

- 源锚点与目标锚点都必须已激活。
- 玩家必须站在源锚点 8 格以内（GUI 传送）。
- 支持跨维度传送。
- 服务端校验所有传送请求。

### 6.2 落点选择

- 在锚点水平四方向寻找可站立位置。
- 优先选择非窒息方块。
- 找不到时回退到锚点自身位置。
- 传送后播放末影人传送音效与传送门粒子。

### 6.3 传送冷却

- 每玩家独立冷却，单位 tick，默认 20 tick。
- 可通过配置关闭（设为 0）。
- 冷却状态保存在内存中，登出时清除（设计行为：退出重进已降低触发频率）。

### 6.4 地图传送

- Xaero 世界地图右键菜单可传送。
- 地图传送不需要站在源锚点旁，但仍需目标已激活，并受冷却限制。

---

## 7. GUI

### 7.1 传送列表

- 显示所有已激活锚点。
- 支持搜索与排序（A-Z / 默认）。
- 每项包含传送按钮与删除按钮。
- 当前正在使用的锚点按钮不可用。

### 7.2 改名界面

- 普通锚点：仅创造模式可编辑。
- 口袋锚点：所有者或创造模式可编辑。
- 服务端再次校验权限与文本合法性。

### 7.3 删除确认弹窗

- 提示“只取消激活，不破坏方块”。
- 确认后发送删除请求。

---

## 8. 权限与安全

| 操作 | 传送锚点 | 口袋锚点 |
|---|---|---|
| 激活 / 传送 | 任意玩家 | 任意玩家 |
| 改名 | 创造模式玩家 | 所有者；创造模式玩家 |
| 破坏 | 可破坏（无掉落） | 可破坏（镐，掉落自身） |

所有改名、删除、传送请求均在服务端重新校验：

- 传送：激活状态、源距离、目标存在、冷却。
- 改名：权限、文本格式、长度。
- 删除：仅能删除自己的激活记录。

## 9. 数据存储

### 9.1 SavedData

| 文件 | 内容 |
|---|---|
| `teleportwaypoint_waypoints` | 全局锚点索引：UID → 维度 / 坐标 / 类型 / 名称 |
| `teleportwaypoint_players` | 玩家 UUID → 已激活锚点 UID 集合 |

- 使用 NeoForge `SavedData`，`DataFixTypes` 为 `null`。
- 读取时对损坏数据做容错跳过。

### 9.2 方块实体 NBT

- 普通锚点：`uid` + `waypoint_id`。
- 口袋锚点：`uid` + `name` + `owner`。
- 旧字段不主动清理，依赖下次保存自然消失。

## 10. 网络同步

### 10.1 同步策略

- **普通传送锚点**：按当前维度全量同步。
- **口袋传送锚点**：只同步已激活的，完整数据也只按当前维度同步。
- **已激活锚点元数据**（UID / 类型 / 名称）：跨维度保留，用于传送列表。

### 10.2 客户端状态

客户端维护：

| 数据 | 内容 | 范围 |
|---|---|---|
| `activated` | 已激活锚点元数据 | 跨所有维度 |
| `waypoints` | 锚点完整数据 | 仅当前维度 |

### 10.3 同步时机

- 登录：发送激活元数据 + 当前维度完整数据快照。
- 跨维度：发送新维度完整数据快照。
- 激活：更新激活元数据；若在当前维度且为口袋锚点，补充完整数据。
- 取消激活：更新激活元数据；若在当前维度且为口袋锚点，移除完整数据。
- 锚点新增/改名/删除：按维度与激活状态定向广播。

### 10.4 分页

- 维度快照按 `MAX_PAGE_SIZE = 500` 分页发送。
- 客户端在 `page 0` 重置当前维度数据，`done` 时完成快照。

### 10.5 协议版本

- 网络 channel 版本：`"3"`。
- 协议不匹配的客户端/服务器应拒绝连接。

## 11. 配置

配置文件位于 `config/teleportwaypoint/`：

| 文件 | 内容 |
|---|---|
| `common.toml` | 传送冷却、可选数据包（原版/YUNG 默认开关） |
| `xaero-minimap.toml` | Xaero 小地图联动配置 |
| `xaero-worldmap.toml` | Xaero 世界地图联动配置 |

### 11.1 通用配置

- `teleportCooldownTicks`：传送冷却（tick），默认 20。
- `可选数据包` 分组：
  - `defaultEnableStructureWaypoints`：新世界默认启用原版结构数据包。
  - `defaultEnableYungStructureWaypoints`：新世界默认启用 YUNG 结构数据包。

### 11.2 Xaero 小地图

- `showWaypoints`：总开关。
- `range`：显示范围，默认 256，0 为不限。
- `waypoint.showInactive` / `waypoint.showActive`：普通锚点未激活/已激活显示开关。
- 口袋锚点仅在激活后显示，无独立开关。

### 11.3 Xaero 世界地图

- `showWaypoints`：总开关。
- `waypoint.showInactive` / `waypoint.showActive`：普通锚点显示开关。
- 口袋锚点仅在激活后显示。
- 无 range（世界地图为全局视图）。

## 12. 数据包与结构生成

### 12.1 原版结构数据包

- 路径：`data/teleportwaypoint/datapacks/vanilla_structure_waypoints`
- 覆盖部分原版结构入口 NBT，加入传送锚点。
- 默认启用，可在世界数据包界面关闭。

### 12.2 YUNG 结构兼容数据包

- 路径：`data/teleportwaypoint/datapacks/yung_structure_waypoints`
- 覆盖 YUNG 系列结构入口 NBT。
- 默认启用，可在世界数据包界面关闭。

## 13. 客户端渲染

### 13.1 方块实体动态渲染（BER）

- 四颗柱顶水晶悬浮错相浮动。
- 晶核绕 Y 轴自转。
- 能量环反向旋转并上下浮动。
- 核心光球呼吸式脉冲缩放。
- 使用全亮光照，夜晚清晰可见。

### 13.2 状态配色

- 传送锚点：未激活红色 / 已激活青色。
- 口袋锚点：未激活黄色 / 已激活绿色。

### 13.3 物品 3D 展示

- 物品栏与手持显示完整方块模型。
- 传送锚点青色 / 口袋锚点绿色。

---

## 14. Xaero 集成

### 14.1 小地图

- 只注册当前玩家所在维度的锚点。
- 普通锚点：未激活红色 / 已激活青色。
- 口袋锚点：已激活绿色，未激活不显示。
- 支持 range 过滤。
- 使用单一 custom waypoint key：`teleportwaypoint:minimap`。

### 14.2 世界地图

- 自定义 element 渲染器。
- 当前维度显示普通锚点 + 已激活口袋锚点。
- 其他维度不显示锚点（因为客户端只持有当前维度完整数据）。
- 右键菜单：名字、坐标、传送。
- 已修复下界/末地坐标缩放问题（`shouldBeDimScaled = false`）。

### 14.3 配置镜像

- 模组 NeoForge 配置为唯一数据源。
- Xaero 设置界面中的相关选项仅作镜像显示。
- 配置写入有缓存，仅在值变化时写入。

## 15. 兼容性

- Minecraft `1.21.1`。
- NeoForge `21.1.236+`。
- 客户端与服务端均可用，客户端类仅在客户端加载。
- 未安装 Xaero 时完全正常运行。

## 16. 已知限制

- 口袋锚点破坏掉落不保留锚点数据，属于设计行为。
- Xaero 小地图全局名称字号会跟随距离文本字号同步。
- Xaero 世界地图切换到其他维度时不显示锚点。
- 普通锚点跨维度完整数据不会保留，仅保留激活元数据。
- 客户端登出时会清空状态，不会持久化锚点缓存。

## 17. 未来方向
